# Licenças das fontes

Todas as fontes desta pasta são distribuídas sob a SIL Open Font License 1.1. O texto completo de cada licença está no `OFL.txt` da pasta da fonte. Os arquivos foram baixados do repositório google/fonts (`ofl/`) e renomeados sem colchetes.

|---|---|---|---|---|
| Space Grotesk | `space-grotesk/` | `SpaceGrotesk-VF.ttf` (variável, wght 300–700) | Títulos | Copyright 2020 The Space Grotesk Project Authors |
| Inter | `inter/` | `Inter-VF.ttf` (variável, opsz 14–32, wght 100–900) | Texto da interface | Copyright 2020 The Inter Project Authors |
| JetBrains Mono | `jetbrains-mono/` | `JetBrainsMono-VF.ttf` (variável, wght 100–800) | Números e status | Copyright 2020 The JetBrains Mono Project Authors |
| Silkscreen | `silkscreen/` | `Silkscreen-Regular.ttf`, `Silkscreen-Bold.ttf` | Letreiros, placas e HUD | Copyright 2001 The Silkscreen Project Authors |
| VT323 | `vt323/` | `VT323-Regular.ttf` | Balões e nomes pequenos no escritório | Copyright 2011, The VT323 Project Authors |
